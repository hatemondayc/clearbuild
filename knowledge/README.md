# 요약: knowledge 폴더(준-RAG 자료 창고)의 문서 관리 규칙 — 파일명·상단 요약·구조·갱신·출처

## 이 폴더는?
CLEARBUILD 사업 자료를 한곳에 모은 **준-RAG 자료 창고**. Claude Code에게 "knowledge 폴더를 참고해서…"라고 하면 이 폴더의 MD 파일들을 읽고 내 자료에 맞춰 답한다. 서버·DB 없이 폴더가 곧 AI의 기억 저장소.

## 4가지 관리 규칙 (자료가 쌓여도 안 헷갈리게)
1. **파일명에 내용이 보이게** — 예: `PRD_lite.md`, `경쟁사_분석.md` (`doc1.md`·`파일.md` 금지)
2. **파일 상단 메타 3줄** — `# 파일명` / `# 날짜` / `# 요약` (AI가 이름표처럼 읽고 맞는 파일 선택)
3. **헤딩·표·목록으로 구조화** — 줄글 한 덩어리 금지
4. **오래된 정보는 갱신** — 수치가 바뀌면 상단 `# 날짜`를 고치고 최신 내용으로 교체

## 출처·갱신일 규칙
- 수치는 **출처 표기** — 검증됨(예: TAM 77조 = 대한경제·헤럴드) vs **자체 추정·확인 필요**(예: SAM 20조·SOM 8,000억)를 구분해 적는다.
- 파일 수정 시 상단 `# 날짜`를 갱신일로 바꾼다.
- 확인 못 한 값은 **"확인 필요"로 명시**하고 지어내지 않는다.
